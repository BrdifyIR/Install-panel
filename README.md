# 🚀 Pasarguard Auto-Installer - ابزار نصب خودکار و مدیریت پنل پاسارگاد

---

## ✨ قابلیت‌های کلیدی (Features)

⚡ نصب کاملاً خودکار (Auto Setup): عبور خودکار از سوالات خسته‌کننده نصب (مانند تایید نصب Node، پورت‌ها، تنظیمات پیش‌فرض SSL و ساخت سرویس Systemd) با استفاده از پاسخ‌های از پیش تعیین شده.

 🗄️ پشتیبانی از ۵ دیتابیس مختلف: نصب و راه‌اندازی پنل پاسارگاد تنها با انتخاب دیتابیس دلخواه شما از بین:
 
• TimescaleDB

• SQLite

• MySQL

• MariaDB

• PostgreSQL

🔒 مدیریت هوشمند SSL: نصب پیش‌نیازها و دریافت کاملاً خودکار گواهینامه معتبر Let's Encrypt (با استفاده از acme.sh یا certbot) و جایگذاری مستقیم فایل‌های .pem در مسیر اختصاصی پاسارگاد (/var/lib/pasarguard/certs/).

🔑 تولید کلید موقت: امکان ساخت سریع توکن و کلید لاگین موقت (Generate Temp Key) بدون نیاز به حفظ کردن دستورات طولانی.

☁️ سیستم بکاپ تلگرامی: فعال‌سازی و مدیریت سرویس backup-service برای ارسال امن بکاپ‌های پنل به ربات تلگرامی شما.

🔄 بازگردانی اطلاعات (Restore): ریستور کردن سریع فایل‌های بکاپ با یک کلیک در منو.

## 🚀 دستور نصب و راه‌اندازی (Installation)

برای اجرای اسکریپت روی سرور خود، ابتدا ترمینال را باز کرده و با دسترسی Root دستور زیر را کپی و اجرا کنید:

```bash
curl -sSL https://raw.githubusercontent.com/BrdifyIR/Install-panel/main/Install.sh -o Install.sh && chmod +x Install.sh && ./Install.sh
```

## 💻 راهنمای استفاده از منو (Interactive Menu)

پس از اجرای اسکریپت، منوی تعاملی زیر برای شما باز می‌شود که شامل گزینه‌های مدیریت کامل پنل است:

گزینه‌های 1 تا 5: نصب سریع و خودکار پنل پاسارگاد بر پایه دیتابیس انتخابی شما (از TimescaleDB تا PostgreSQL).

6) Install SSL Certificate for Panel: با وارد کردن ایمیل و دامنه خود، اسکریپت به صورت خودکار سرتیفیکیت SSL را دریافت کرده و در پوشه اختصاصی دامنه در سرور پاسارگاد ذخیره می‌کند.

7) Generate Temp Key (Token): اجرای دستور ساخت توکن برای دسترسی سریع به پنل و ساخت ادمین.
  
8) Backup Panel to Telegram Bot: اجرای فرآیند سرویس پشتیبان‌گیری پاسارگاد و ارسال بکاپ‌ها به ربات تلگرام.

9) Restore Backup: فراخوانی سیستم بازگردانی پاسارگاد برای ریستور کردن بکاپ‌های قبلی.

0) Back to Main Menu / Exit: خروج امن از برنامه یا بازگشت به منوی قبلی.
